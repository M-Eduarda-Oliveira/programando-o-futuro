Sobre o projeto

Este projeto foi criado para praticar os fundamentos do CSS. A ideia é partir de um HTML simples e, aos poucos, transformar a página usando cores, espaçamentos, fontes e layout.

Na próxima etapa, vamos adicionar JavaScript para validar o formulário e deixar a página mais interativa.
